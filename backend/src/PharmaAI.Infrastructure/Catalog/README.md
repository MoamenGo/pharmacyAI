# Bundled Egyptian drug list

`egyptian-drugs.csv.gz` is the Egyptian Drug Database by karem505
(https://github.com/karem505/egyptian-drug-database, data/egyptian-drugs.csv, June 2026 snapshot),
released under CC0-1.0. It lists medicines registered in Egypt with Arabic and English trade names,
active ingredients, manufacturer, route and the retail price in EGP. It has no barcodes.

The app only uses it as reference data when adding a drug: the cashier still scans the barcode and
checks the price on the box. To update it, download the latest CSV and gzip it over this file.
